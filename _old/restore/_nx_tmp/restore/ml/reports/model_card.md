# Model card: phishing email classifier

## Details

Soft-vote ensemble of a HistGradientBoosting classifier on URL and header
features and a tuned logistic regression on text, URL and header features.
Built with scikit-learn. Seed 6850. Julian Calvo, AAI6850 capstone, August 2026.

## Intended use

Flagging likely phishing email inside an organisation's own mail
infrastructure, where SPF, DKIM and DMARC results are trustworthy. Intended as
one signal among several, not as an autonomous quarantine decision.

## Out of scope

Non-English mail. Attachment or image analysis. Anything outside the receiving
infrastructure, where the header features can't be trusted. Any deployment
where a false positive is unrecoverable.

## Training data

8,000 synthetic records (3,356 phishing, 4,644 benign) from 114 templates and
1,574 near-duplicate groups, generated by `data/build_dataset.py` with 1.5%
deliberate label noise. Split with StratifiedGroupKFold on group id, zero group
overlap between splits. The corpus is synthetic because the build machine can't
reach the public phishing datasets, which is this model's biggest limitation.

## Metrics

Test set, 1,600 records, at threshold 0.272:

| Metric | Value |
|---|---|
| Accuracy | 0.966 |
| Precision | 0.957 |
| Recall | 0.963 |
| F1 | 0.960 |
| ROC-AUC | 0.981 |
| PR-AUC | 0.974 |

Threshold picked to minimise expected cost with a false negative weighted 4x a
false positive, subject to precision staying above 0.90.

## Known failure modes

Phishing sent from domains that pass all three authentication checks (12 of 25
false negatives). Legitimate mail containing no URLs, where the URL features
contribute zeros that push toward phishing (most false positives).

## Ethics

Reads email content, so it should run inside the buyer's boundary. English-only
training data. Freemail sender is a top phishing feature, which risks penalising
small businesses that legitimately send from freemail addresses. Feature
engineering is public in `src/features.py`, which also makes it easier to evade.

## Reproducing

`npm run ml:all` from the repo root. About 95 seconds.
